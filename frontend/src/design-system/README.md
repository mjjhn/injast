# Design system

این پوشه تنها مرجع کنترل‌ها، توکن‌ها و الگوهای تعاملی مشترک رابط است.

## لایه‌ها

- `tokens.css` تنها منبع رنگ، فاصله، شعاع، لایه و تایپوگرافی است.
- `atoms/` کنترل‌ها و نمایش‌های پایه مانند `Button`، `Input`، `Toast` و `Money` را نگه می‌دارد.
- `molecules/` از atomها composition می‌کند؛ مانند `FormField`، `MoneyInput` و `DateField`.
- `primitives/` مرزهای تعاملی سطح‌بالا را نگه می‌دارد: `Modal` برای تصمیم‌های تأییدی؛ فرم واریز در خود صفحهٔ جزئیات می‌ماند.
- `layout/` اسکلت صفحه و ناحیه‌های ثابت بالا/اسکرول/عمل پایین را فراهم می‌کند.

## قانون وابستگی

وابستگی فقط به سمت پایین است: صفحات feature از design-system استفاده می‌کنند؛
design-system به API یا مدل‌های feature وابسته نیست. صفحات فقط composition انجام
می‌دهند و style اختصاصی تکراری برای کنترل‌های مشترک ندارند.

برای حفظ code splitting، routeها از barrelهای همان لایه یا public entrypoint
استفاده می‌کنند و importهای سنگین تقویم/فرم را به مسیر موردنیاز محدود می‌کنند.
